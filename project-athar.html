Athar

A bilingual architecture experience designed and built from scratch, using motion, code and an AI-assisted workflow as part of the design process.

https://athar-works.vercel.app/ ↗
THE STARTING POINT

I wanted the website to feel architectural, not simply display architecture.

Athar gave me room to design without a conventional handoff boundary. I started with pacing, composition and movement rather than a stack of static sections, asking how the interface itself could carry some of the atmosphere of the studio’s work. The plan was to use motion with restraint: enough to make the site feel spatial and alive, but never so much that it competed with the projects.

THE EXPERIENCE IN MOTION

Athar is built around pacing, transitions and responsive movement. This short loop gives a glimpse, but the live site is still the real case study.

THE SCREENSHOT CANNOT DO THIS PROJECT JUSTICE

Athar was designed to be experienced, not flattened.

Motion, transitions, pacing and interaction are part of the design language. The site uses the browser as part of the architectural experience, so this case study intentionally stops short of pretending a stack of screenshots can replace the real thing.

https://athar-works.vercel.app/ ↗
THE APPROACH

Design and implementation stayed in the same creative loop.

I shaped the visual direction, responsive behavior, transitions and interactions, then used Claude and an AI-assisted development workflow to build and refine the site directly. GitHub, Vercel and practical HTML/CSS let me inspect generated code, troubleshoot issues and deploy iterations myself rather than treating the build as a black box. Testing ideas in the browser changed some of the design decisions because timing and movement are impossible to judge fully in a static file.

THE RESULT

The live experience became the real case study.

Athar is intentionally difficult to flatten into screenshots because motion, pacing and interaction are part of the visual language. It showed me how much faster and more confidently I can iterate when design and implementation are allowed to inform each other, and it pushed my website work further toward experiences that are conceived for the browser from the beginning.
