Athar

A bilingual architecture experience designed and built from scratch, using motion, code and an AI-assisted workflow as part of the design process.

https://athar-works.vercel.app/ ↗
THE IDEA

I wanted the website to feel architectural, not just show architecture.

Athar started as an opportunity to design without a conventional handoff boundary. I planned the experience around pacing, composition and movement so the interface itself could carry some of the atmosphere of the studio’s work. That meant thinking beyond static sections and deciding where transitions, responsive movement and restraint could make the experience feel more spatial.

THE EXPERIENCE IN MOTION

Athar is built around pacing, transitions and responsive movement. This short loop gives a glimpse, but the live site is still the real case study.

THE SCREENSHOT CANNOT DO THIS PROJECT JUSTICE

Athar was designed to be experienced, not flattened.

Motion, transitions, pacing and interaction are part of the design language. The site uses the browser as part of the architectural experience, so this case study intentionally stops short of pretending a stack of screenshots can replace the real thing.

https://athar-works.vercel.app/ ↗
DESIGNING IN THE BROWSER

The implementation became part of the creative loop.

I shaped the visual direction and interactions, then used Claude and an AI-assisted development workflow to build and refine the site directly. GitHub, Vercel and practical HTML/CSS let me inspect, troubleshoot and deploy the work instead of treating generated code as a black box. The result is intentionally difficult to summarize with screenshots: the live experience is the case study. Athar taught me how much faster I can iterate when design and implementation are allowed to inform each other.
