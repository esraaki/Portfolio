A scalable website system for a family of 16 companies, designed to stay consistent underneath while letting each brand look like itself.

THE PROBLEM

Sixteen websites made this a system problem before it was a page-design problem.

As the sole designer, I knew a beautiful one-off homepage would not solve the real challenge. I planned a reusable structure that could absorb different logos, typography, colors and imagery without creating sixteen unrelated experiences. The client wanted the direction clean, modern, strong and straightforward, so I deliberately avoided unnecessary decoration and built flexibility into the parts that actually needed to change.

THE WORKFLOW + RESULT

I moved the first direction into the browser early.

Instead of relying only on static Figma screens, I built the first variation on staging so the team could experience responsive behavior and interactions in context. I used GitHub, Vercel, practical HTML/CSS and an AI-assisted workflow to make the concept tangible and fast to revise, including a brand-variation test across different PowerGrid companies. The biggest lesson was that implementation can be part of design thinking: testing the system live exposed decisions earlier and made feedback more concrete.
